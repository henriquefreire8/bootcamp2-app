# Pokédex Simples

## Autor
Henrique Cysne Furquim Freire — Matrícula 22605332

## Descrição
Aplicação web simples que permite buscar um Pokémon pelo nome e ver sua imagem, altura e peso. Ideal para fãs de Pokémon que querem consultar informações rapidamente.

## API utilizada
- PokeAPI — https://pokeapi.co/
- Endpoint consumido: `GET https://pokeapi.co/api/v2/pokemon/{nome}`

## Funcionalidades
- Buscar um Pokémon digitando o nome (em inglês)
- Ver imagem, altura e peso do Pokémon
- Mensagem amigável quando o Pokémon não é encontrado

## Como executar localmente
1. Clone: `git clone URL_DO_REPOSITORIO`
2. Abra o arquivo `index.html` no navegador
